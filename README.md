# Commandes magasins

Application de commandes clients pour Prod Colomiers, Prod Muret, Prod Pamiers, Prod Dax et la centrale d'achat.

- Page : `index.html` (hébergée par GitHub Pages)
- Connexion et données : projet Firebase `commandes-prod` (`config.js`)
- Règles d'accès Firestore : `firestore.rules` (à coller dans la console Firebase, onglet Règles)
